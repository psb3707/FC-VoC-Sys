# ADR-013. S1 화면 동일화를 위한 예외 (원본 직접 열람, 로고·캐릭터 이미지, 시안 띠 숨김)
- 상태: 승인 (사용자 지시, 2026-11-02)
- 일부 대체: ADR-011 결정 2(원본 직접 열람 금지), ADR-012(회사 로고 미사용, 스크린샷 취급), CLAUDE.md 프론트 단계 규칙(시안 띠 표시)

## 결정
- 원본 열람: 사용자가 이번 한 번 허용해 Claude가 Playwright 로 원본 저장본을 열어 요소별 크기·색·글꼴 수치를 측정했다. 원본·캡처는 저장소·앱에 넣지 않았고 작업 후 삭제했다. 이름·일정 등 데이터는 가져오지 않았다(가상 데이터 유지).
- 이미지: 사용자가 제공한 로고(`static/img/logo.png`)와 캐릭터(`static/img/mascot.png`, 배경 투명 처리)를 헤더·날짜 카드에 쓴다. 외부 공개 자료에는 넣지 않는다.
- 글꼴: Noto Sans KR(SIL OFL)을 `static/fonts/`에 포함한다. 서버 없이 열려야 하므로 웹에서 가져오지 않는다.
- 시안 띠: 화면에서 숨긴다(`display:none`). 역할 전환은 주소 `#role=…`로 한다.

## 영향
- 회사 식별 요소가 저장소에 들어간다. 저장소가 외부 공개되면 로고·캐릭터를 빼야 한다(`static/img/`).
- 시안 표시가 없으므로 발표·시연 때 "화면 시안"임을 구두로 알린다.
