# ADR-012. S1은 실제 SFA 화면을 HTML로 충실히 재현하고 실데이터 자리는 가상 데이터로 채운다
- 상태: 승인 (사용자 지시, 2026-11-02 "화면 구조 자체가 기존 SFA와 너무 차이가 크다. 목표는 거의 완벽할 정도로 동일하게 기존 SFA 화면을 복제하고 거기에 기능을 얹는 것")
- 일부 대체: ADR-005(가린 캡처 배경 `sfa-main-masked.png` 방식), ADR-011 결정 1의 "캡처 이미지" 행

## 배경
- 첫 S1 목업(회색 레이아웃 블록 + 진입점 3개)은 실제 SFA와 배치·비율·색이 크게 달라, 임원 청중에게 "쓰던 화면에 창구 하나가 생겼다"는 인상을 주지 못했다.
- 사용자가 실제 메인 화면 스크린샷(1888×952)을 기준으로 제공했다. 스크린샷에는 실명·고객·일정 등 실데이터가 들어 있다.

## 대안
| 대안 | 장점 | 단점 | 결정 |
|---|---|---|---|
| A. 가린 스크린샷을 배경 이미지로 깔고 진입점만 얹기 (기존 ADR-005 방식) | 모양이 원본과 같음, 작업 적음 | 가림 누락 위험이 이미지 전체에 남음, 해상도마다 어긋남, 탭·팝업이 실제로 눌리지 않음, 이미지가 저장소에 들어감 | 불채택 |
| B. HTML/CSS로 충실 재현 + 실데이터 자리는 가상 데이터 | 저장소에 실데이터가 들어갈 여지가 없음, 해상도 대응, 진입점과 기존 요소를 같은 CSS로 그림, 다음 단계(패널) 연결 쉬움 | 재현 작업량, 원본과 미세한 차이 | **채택** |

## 결정
- S1은 실제 SFA 메인 화면의 **구조·비율·색·모서리·그림자를 HTML/CSS로 충실히 재현**한다(상단 헤더, 파란 탭 바, 왼쪽 사용자·실적·활동량 카드, 가운데 날짜 카드·요약 알약·업무 탭·공지 탭·배너, 오른쪽 퀵메뉴).
- 이름·숫자·일정·표·공지 제목은 모두 **가상**(`js/fixtures/`). 사람 이름은 "(가상)" 또는 코드(FC-01). 회사명·서비스명·로고·상품 브랜드는 쓰지 않는다(중립 로고 자리, "가상 종신보험 A", CSS로 그린 중립 배너).
- 진입점 3개(퀵메뉴 "전산 오류 접수", 공지 탭 "알려진 오류·내 신고", 알림 아이콘 배지+팝업)는 재현한 기존 요소와 **같은 CSS**로 얹는다.
- "화면 시안 – 실제 동작 안 함" 띠와 역할 전환은 SFA 화면 **바깥 위 띠**에 둔다. `?compare=1` 이면 띠를 숨겨 재현도 비교 캡처에 쓰인다.

## 스크린샷 취급 규칙
- 원본 스크린샷은 **저장소 밖**(사용자 PC)에만 둔다. 원본·흐림 사본 모두 Git·앱·외부 공개 자료에 넣지 않는다.
- Claude(외부 LLM)는 원본을 Read 등으로 **직접 열람하지 않는다.** `scripts/ref_blur.py` 로 만든 **흐림 6px 이상 사본**만 본다(6 미만은 스크립트가 거부). 확대는 흐림 뒤에 한다(글자가 읽히지 않게). 사본은 `target/`(Git 제외) 아래에 둔다.
- 재현도 비교(`scripts/ui_compare.py`)도 원본을 흐림 없이 출력·저장하지 않는다.

## 재현도 확인 방법
- `python scripts/ui_compare.py "<원본 경로>" [--blur 6] [--offset-y N]`
  - 우리 `index.html?compare=1` 을 원본 크기로 headless Chrome 캡처 → 두 이미지에 같은 흐림 → 픽셀 차이로 전체 유사도(%)와 8×6 격자별 유사도.
  - `target/ui-compare/` 에 흐림 원본·흐림 재현을 **반반 겹친 PNG**와 **나란히 놓은 PNG** 저장.
- 숫자보다 겹친 이미지에서 상자 위치·크기·색이 맞는지를 우선 본다. 가상 데이터 글자 차이는 허용.

## 영향
- 폐기: 가린 캡처 배경 `assets/sfa-main-masked.png` 방식. 06(0절 6항, S1), 08(6절), 01(REQ-IN-10 문구), 03(디렉터리), 12(M1 체크리스트·일정), ADR-005·009·011 문구를 정리한다.
- 06 0-1 토큰을 재현 값으로 보정, 11절에 `ref_blur.py`·`ui_compare.py` 사용법 추가. `CLAUDE.md` 보안 절에 스크린샷 규칙 추가.
- 원본 HTML(`references/`) 접근 방식(ADR-011 결정 2)은 그대로 유지한다.

## 일정 영향
- 재현 작업 +1~1.5일(프론트 주간). 12번 R13(프론트 검토가 길어져 백엔드 기간 잠식) 위험이 커진다. 대응: 재현은 S1 한 화면에 한정, 미세한 차이는 백로그, 패널(S2) 이후 화면은 새 접근성 기준으로 만들어 재현 대상이 아님.
