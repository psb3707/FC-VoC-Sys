# ADR-022. 화면 첨부와 AI 접수 초안 시연

요구사항 정의서 2차의 EXT-03, EXT-04를 적용한다. 두 화면 일반 접수와 기존 AI 문의의 직접 접수는 계속 사용할 수 있다.

- 공통 확인 화면에서 PNG/JPEG 한 장을 선택한다. 문제 영역 자르기와 불투명 가림을 브라우저 안에서 적용하고, 설계사가 최종 미리보기를 확인한 이미지 한 장만 접수에 붙인다. 가림 전 파일과 파일 이름은 공유 저장소나 AI 경로에 전달하지 않는다.
- 가상 결함 대장의 영업팀·IT 담당만 확정 이미지 조회 API를 사용한다. 제한·첨부 실패 시 다시 시도하거나 파일을 빼고 제출한다. 화면 이미지 열람 권한, 실제 업로드·보관 정책은 운영 연동에서 서버 검증이 필요하다.
- AI 문의에서 선택적으로 초안을 열고, 전송 전 가려진 텍스트를 확인한다. 입력과 수집값으로 채운 항목을 제외해 최대 세 가지를 묻는다. 질문은 개별 또는 전체 건너뛰기가 가능하다. 확인 화면에서 고객 진술·직접 확인·재현 순서·시도·영향과 미확인 상태를 나누고 수정한 뒤 제출한다.
- FRONTEND에서는 규칙과 가상 AI 응답으로 동작을 검증한다. 자유 입력 초안·추가 설명은 기존과 같이 현재 페이지 메모리에 두고, 공유 저장소에는 가상 접수의 구조화 상태와 확정 이미지만 둔다. 운영 AI·권한·보관과 EXT-05/06은 후속 범위다.
- 기존 입력란, 상태 안내, 접힌 영역, 콘텐츠 카드와 보조/주 버튼 토큰을 사용한다.
