# ADR-021. 접수 진단정보와 해결 알림 시연

2026-11-09 요구사항 정의서의 1차 범위(EXT-01, EXT-02)를 적용한다. 두 화면 접수와 AI 문의에서 같은 접수 양식으로 이어지는 동작을 유지한다.

- 허용 목록을 거친 가상 진단정보를 접수 환경과 발생 환경으로 나눠 보여 준다. 자동 수집값은 확인 화면에서 펼칠 수 있고 발생 환경을 직접 보완할 수 있다. 실패해도 제출할 수 있다.
- 담당자는 새 접수를 대표 결함에 직접 연결한다. 해결을 확정할 때 적용 시각·범위·변경 내용·기존 건의 후속 조치와 공개 여부를 확인한다. 한 상태 변경의 알림은 수신자별로 한 건이며 해당 접수번호로 이동한다. 실패한 알림은 대장에서 재시도한다.
- FRONTEND에서는 두 화면의 가상 접수번호, 허용된 구조화 진단·상태·읽음·이력을 같은 브라우저의 저장소에서 공유한다. 설명과 추가 내용의 자유 입력 원문은 현재 페이지 메모리에 둔다. 기존 숫자 단계와 실험은 변경하지 않는다. 실제 SFA 로그, 서버 저장, 운영 인증·발송과 목표 시간 검증은 백엔드·운영 범위다. EXT-03/04와 시범 EXT-05/06은 정의서 순서대로 후속 적용한다.
- 확인 정보, 알림, 대장 상세는 06번 0-3절의 접힌 영역·콘텐츠 카드·정의 목록·기존 알림 패널 토큰을 사용한다.
