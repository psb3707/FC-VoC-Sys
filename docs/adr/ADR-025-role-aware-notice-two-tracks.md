# ADR-025. 역할별 알림과 두 갈래 진행 표시

- 상태: 승인 (사용자 결정, 2026-11-15)
- 근거: 알림 기능 개선 제안 검토(2026-11-15). "처리상태가 변경되었습니다" 대신 "지금 할 일 + 근본 수정이 어디까지 왔는지"를 알린다.
- 개정: `02-domain-rules.md` 4절(수신자·대리 접수 알림), ADR-015의 내 신고 카드 구성과 "받은 알림" 목록, ADR-018의 AI 문의 결과 카드 구성
- 유지: 대표 결함 상태 7종과 전이 규칙(02번 3절), 알리는 상태 변경 4가지(임시조치·수정 예정·해결·수정하지 않음), ADR-017(연결은 담당자), ADR-019(두 화면 접수), ADR-021(자유 입력 원문은 저장소에 두지 않음), S5 실험 경로(숫자 단계·`known=off`)
- 번호: ADR-023·024는 머지되지 않은 다른 브랜치가 쓰고 있어 겹치지 않게 025를 쓴다.

## 배경
FC, 대신 접수한 지점 관리자, IT·영업 담당자가 같은 알림을 다른 이유로 본다. 지금 알림은 결함 상태만 말해서 "임시조치"를 "해결됨"으로 오해하기 쉽고, 관리자가 대신 접수하면 신고자(FC)만 알림을 받아 접수한 관리자는 결과를 모른다. FC가 안내대로 업무를 이어갔는지도 기록되지 않는다.

## 결정
1. **두 갈래 진행 표시.** 대표 결함 정보를 FC에게 보일 때는 항상 ① "지금 업무를 이어갈 수 있나요?"(승인·공개된 임시 방법, 해결이면 기존 건 처리 방법)와 ② "근본 오류는 언제 고쳐지나요?"(수정 예정일·해결·수정하지 않음 사유, 정해지지 않았으면 "아직 정해지지 않았어요")를 나눠 보인다. AI 문의 결과, S3 오류 현황·내 접수내역, 관리자 묶음 보기에 같은 모양을 쓴다.
2. **내 문의 처리는 사실만.** 신고가 대표 결함에 연결되기 전에는 "접수됨 · 담당자 확인 전", 담당자가 연결한 뒤에만 "담당자가 확인했어요"라고 쓴다. 연결이 곧 담당자 확인이다(대장 연결은 담당자만 한다, ADR-017·021). 새 인수 버튼은 두지 않는다.
3. **대리 접수 알림.** 관리자가 FC 대신 접수하거나 참여하면 FC에게 접수 알림 1건이 생긴다(FC는 접수 화면을 못 봤기 때문). 관리자는 접수 완료 화면을 봤으므로 접수 알림을 받지 않는다. 확인 화면에서 "이 문의는 ○○ FC의 접수내역에 등록되고, 경과는 FC와 나에게 함께 안내돼요"를 보인다.
4. **상태 변경 알림 수신자.** 알리는 상태 변경(02번 4절)이면 연결된 신고의 신고자(FC)와, 신고자와 다른 대리 접수자(관리자)에게 보낸다. 한 변경에 한 사람은 1건이다. 같은 사람이 신고자이기도 하면 신고자 알림만 간다. 관리자 알림은 "대신 접수한 문의 N건"으로 묶는다. 문구는 받는 사람 역할별로 다르다(FC: 지금 할 일, 관리자: FC 업무 재개 확인 요청).
5. **FC 업무 재개 회신.** 임시 방법이 있는 내 접수에 "이 방법으로 업무를 이어갈 수 있었나요?" [네, 진행했어요] / [아직 안 돼요]를 둔다. 신고자 본인만 답한다. 답은 결함 상태를 바꾸지 않는다. [아직 안 돼요]는 그 접수의 후속 기록("아직 안 돼요", ADR-019)으로도 남기고, 긴급 사정을 바로 남길 수 있게 한다. 실제 전화·메신저 연결은 없다.
6. **관리자 묶음 보기.** 관리자 역할(`MANAGER`, 부지점장·지점장을 나누지 않음)은 S3 패널에 세 번째 탭 [지점 FC 문의]를 본다. 범위는 같은 지점 FC의 문의와 내가 대신 접수한 문의다. 대표 결함별로 묶어 FC 수, 업무 재개 회신(진행했어요·아직 안 돼요·답 없음), FC의 알림 확인 여부를 따로 보인다. FC가 적은 설명과 고객 정보는 보이지 않는다(내가 대신 접수한 건 제외).
7. **알림 원칙.** 접수 완료 ≠ 담당자 확인, 임시조치 ≠ 근본 해결, 수정 예정 ≠ 수정 완료(예정일이 있을 때만 날짜), AI 추천 ≠ 같은 결함 확정(공개 사례는 "비슷해 보이는"으로만), 같은 변경은 사람별 1건.
8. **알림에서 바로 행동으로.** FC 알림은 그 접수 카드를 펼친 채 열고, 관리자 알림(대리 접수자용)은 [지점 FC 문의]의 그 결함 카드를 연다. 내 접수내역의 "받은 알림" 목록은 빼고(종 모양 팝업과 중복), 카드는 "어느 건 / 지금 어디까지 / 나는 뭘 하면 되나"만 보이고 나머지는 [자세히 보기]에 접는다.

## 보류 (이번 범위 밖)
- 지점장 전용 지점 요약, 부지점장·지점장 역할 구분
- 새 알림 이벤트(긴급 장애 확인, 일정 변경, 반복 발생)
- 관리자가 "FC에게 안내했어요"를 기록하는 표시
- 실제 문자·메신저·전화 연결
