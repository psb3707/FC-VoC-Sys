# ADR-001. A모드에도 한 줄 입력을 둔다
- 상태: 승인 (사용자 답변, 2026-11-02)
- 배경: 요청 2절은 "선택형 대 선택형+한 줄+AI 되묻기", 3절은 "AI 기능만 끈 버전"이라 서로 다르게 읽혔다. 한 줄 입력이 없으면 시나리오별 핵심 조건(예: 세미나 초대장 발송 이력)을 A모드에서 적을 곳이 없어 B가 구조적으로 유리해진다.
- 대안: (a) A에 한 줄 입력 (b) A는 선택 항목만 (c) A에 선택 입력 "기타" 메모만
- 결정: **(a)**. A = 선택 + 한 줄, B = A + AI 구조화·되묻기. 비교 대상은 AI의 효과 하나.
- 영향: 01 REQ-MD-01, 06 S2 5·6단계(`mode`로 AI 부분만 켜고 끔), 09 설계. A모드 유형은 "미분류".
- 한계: 제안서 6.1의 "양식" 비교 의미가 "현행 양식 대비"가 아닌 "AI 단계 유무 대비"로 좁아진다. 발표에서 이 정의를 명시한다.
