# ADR-005. 원본 SFA HTML은 쓰지 않고 가린 캡처로 목업을 새로 만든다
- 상태: 승인 (요청 4절 1항, 2026-11-02 전달 자료 확인 후 재확인)
- 배경: `references/sfa_home.html`은 로그인 상태에서 저장한 실제 페이지(2.4MB)로, 실존 인물로 보이는 호칭 표현과 긴 숫자를 포함한다. 회사 서비스명·로고도 있다.
- 결정: 이 파일은 배치·메뉴 이름 참고용. 앱·Git·외부 전송 모두 금지. 목업 배경은 메인 화면을 캡처해 개인·실적 정보와 회사 식별 요소를 가린 `assets/sfa-main-masked.png`로 새로 만든다(11/13까지).
- 영향: 08 6절, 06 S1, 12 R9. Claude 훅이 `references/` 쓰기를 차단한다. 외부 공개 자료에는 이미지를 넣지 않는다.
