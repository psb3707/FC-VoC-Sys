# ADR-002. 비교 검증은 실제 LLM API로 수행한다
- 상태: 승인 (사용자 답변, 2026-11-02). 단 허용 서비스·비용 처리는 미결 Q2.
- 배경: 참가자의 자유 입력은 미리 기록한 Mock 응답으로 충실히 처리하기 어렵다.
- 결정: 실험은 실제 API. Mock은 개발·시연 예비·장애 대비. 공급자·모델·프롬프트는 실험 기간 고정.
- 영향: 07 공급자 전환·실패 처리, 12 R1·R2. 제안서 7.6은 승인을 "확인 필요"로 남겨 두었으므로 11/13 게이트에서 허용 서비스·비용을 확정한다.
- 후퇴: 승인 철회 시 Mock + 규칙 기반 되묻기로 실험하고 결과에 "AI 시뮬레이션"으로 명시.
