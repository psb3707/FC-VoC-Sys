# ADR-024. 과거 사례 목록보다 이번 문의의 대응 판단을 앞세운다

- 상태: 사용자 개선 요청에 따른 구현 (2026-11-10)
- 배경: ‘AI 사례에 물어보기’는 목적이 불분명하고, 사례별 필드를 반복하는 답변은 담당자가 다시 해석해야 한다.
- 결정: 진입점은 ‘이전 처리 방법 찾기’, 열린 영역은 ‘어떻게 대응하면 될까요?’. AI는 관련 기록을 정리하는 보조 설명으로 표시한다.
- 답변은 핵심 답 → 먼저 확인할 것 → 같은 조건일 때 할 일 → 조건이 다르거나 해결되지 않을 때 → 근거 기록 순서다. 가장 관련 있는 답변 하나를 먼저 보여 주고 다른 증상의 기록은 접는다.
- 기록의 상태(임시 대응·조사 중·과거 조치·안내 완료)를 명시한다. 조사 중/오래됨/조건 불일치에는 확정 해결책을 만들지 않고 확인할 내용과 협조 경로를 제시한다.
- ‘서명 오류’처럼 증상이 모호하면 짧은 확인 질문으로 분기를 고른다. 고정 응답의 질문 표현 비교이며 실제 AI 성능 검증은 아니다.
- 특정 접수에서 시작한 경우 ‘이번 건과 비교하기’, ‘현장 안내 초안 만들기’, ‘확인 요청 내용 정리하기’를 제공한다. 초안은 미확인 조건을 확정하지 않고 사람의 검토 후에만 기존 공유 흐름으로 적용한다. 원문 질문과 자유 서술은 URL·영구 저장에 기록하지 않는다.
- 기존 06번 0-3 콘텐츠 카드·입력란·펼침·버튼 토큰을 재사용한다. 답변 안의 반복 카드·표는 짧은 문단과 순서 목록으로 바꾼다. 18px 본문·56px 행동·키보드 포커스 유지.
- ADR-023의 업무 분류·기존 상태·알림·접수 연결·참고 연결·실제 API 후속 범위는 유지한다.
