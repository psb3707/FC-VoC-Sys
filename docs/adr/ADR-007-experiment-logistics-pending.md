# ADR-007. 실험 진행 방식은 보류 (Q1)
- 상태: **보류** (결정 기한 2026-11-27)
- 배경: 사용자 답변이 "일반 이 검증 방식은 보류 처리해줘"였다. 이를 **장소·PC 구성만 미정**으로 해석하고 실험 모드는 Must로 유지했다.
- 후보: (a) PC 1대에서 한 명씩(권장, localhost만) (b) 같은 망의 각자 PC (c) 지점 방문·노트북
- 결정: 보류. 설계는 어느 방식에서도 쓸 수 있게 서버 바인딩을 설정값으로 둔다(기본 127.0.0.1).
- 확인 필요: **실험 자체를 보류한다는 뜻이었다면** 09번 문서·일정을 다시 잡아야 한다.
