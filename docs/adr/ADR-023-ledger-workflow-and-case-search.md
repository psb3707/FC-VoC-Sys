# ADR-023. 업무별 공동 대응과 AI 사례 검색 화면
- 상태: 사용자 개발 요청에 따른 구현 (2026-11-10)
- 배경: FC → 지점 관리자 → 영업팀·영업관리자 → 필요 시 IT 협조 흐름을 지원한다.
- 결정: S4는 업무 문의·오류 관리. 검토 대기 접수/진행 건/처리 사례와 업무별 조회를 제공한다. 업무 영향·담당·다음 조치를 앞세운다.
- 신규 등록·추가정보 요청·안내 종료·이관·재검토를 제공한다. 현재 책임자와 IT 협조 담당, 내부 기록과 현장 공유 내용을 구분한다. 복사와 실제 공유 완료도 구분한다.
- AI 질문·고정 답변·출처·조건 비교·참고 연결을 FRONTEND부터 제공한다. ADR-016에 따라 발표에서 고정 응답임을 설명하며 실제 AI 품질을 검증했다고 주장하지 않는다.
- 기존 Defect 상태 코드와 FC 알림은 유지한다. 관리자 표시에서 RESOLVED는 처리 완료, WONT_FIX는 처리 종료 + 사유로 표현한다. 추가정보 대기·재검토는 업무 메타데이터다.
- 기존 06번 S4의 2탭·AI 우선 배치·영향 지점 곱 정렬은 대체한다. ADR-017의 사람 확인 원칙은 유지한다.
- 디자인은 06번 0-3의 페이지 머리/탭/데이터 표/입력란/콘텐츠 카드/패널을 따른다. 상세 패널 760px, 1280px 미만 전체 폭. 본문 18px·버튼 56px 유지.
- 자유 서술과 AI 질문은 페이지 메모리에서만 유지한다. 구조화 시연 메타는 기존 브라우저 저장소를 재사용한다. 운영 저장·인증·자동 발송·실제 API는 범위 밖이다.
