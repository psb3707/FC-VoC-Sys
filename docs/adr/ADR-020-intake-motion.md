# ADR-020. 접수 완료와 AI 문의에 진행 반응을 표시한다

- 2026-11-08 사용자 요청으로 S2 접수 완료 및 AI 문의 패널에 적용한다.

1. 접수 성공 시 기존 성공 색상과 원형 아이콘에 짧은 등장과 체크 선 그리기를 한 번 적용한다. 완료 문구와 다음 행동은 바로 표시한다.
2. AI 문의에 처음 들어갈 때 제목, 설명, 추천 질문이 짧은 간격으로 나타난다. 질문을 보내면 점 세 개와 처리 상태를 보여 주고, 응답 카드의 내용은 짧게 나누어 표시한다.
3. FRONTEND는 가상 응답을 받는 기존 API를 쓰고 브라우저가 순차적으로 그린다. 실제 모델 토큰 전송은 백엔드 연결 때 다룬다. 입력 차단은 바로 알려 주고, 닫힌 화면의 진행은 화면을 갱신하지 않는다.
4. 모션 줄이기 설정과 검사·비교 주소에서는 완료 체크와 답변을 즉시 표시한다. 상태는 아이콘과 별도로 글자로 전달하고, 스크린리더에는 답변 조각마다 알리지 않는다.

기존 패널의 원형 성공 아이콘, 콘텐츠 카드, 추천 질문 알약, 안내 글자 토큰을 재사용한다. S5 숫자 단계의 접수 입력과 실험 조건은 그대로 사용한다.
