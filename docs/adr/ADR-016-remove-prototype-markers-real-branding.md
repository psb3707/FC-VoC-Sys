# ADR-016. 화면 시안 표시 전부 제거, 실제 로고·캐릭터 사용 확정
- 상태: 승인 (사용자 지시, 2026-11-03 "화면 시안 띠는 제거해야 해. 로고와 캐릭터는 실제로 사용할 거야", 제거 범위: 홈 위 띠와 패널 아래 시안 줄 모두)
- 대체: `CLAUDE.md` 프론트 단계 규칙 "상단에 '화면 시안 – 실제 동작 안 함'을 표시한다", `06-ui-spec.md` 1절 "프론트 단계 표시", ADR-012 결정의 "시안 띠는 SFA 화면 바깥 위 띠", ADR-013 결정의 "시안 띠: 숨김(`display:none`)"(숨김 → 제거), ADR-011·012의 "중립 로고 자리, 회사명·로고 미사용"
- 유지: ADR-013의 로고·캐릭터 이미지 사용과 저장소 외부 공개 시 제거 조건, 실데이터 자리는 가상 데이터(ADR-012)

## 배경
- ADR-013으로 홈 위 시안 띠는 이미 `display:none`으로 숨겨졌지만 마크업·CSS·스크립트와 문서 규칙("상단에 표시")은 남아 있어 문서와 구현이 어긋났다.
- S2·S3 패널 맨 아래에는 "화면 시안 – 실제 동작 안 함" 노란 줄과 "시안 조절"(단계·분기·AI 지연 등 상태 전환) 버튼이 있다. 발표에서 실제 SFA에 창구가 생긴 모습으로 보여 주려면 화면 안의 시안 표시가 방해가 된다.
- 로고·캐릭터는 ADR-013에서 "예외"로 들였지만, 06번 0절·3절은 여전히 "중립 로고 자리"로 적혀 있다. 사용자는 실제 로고·캐릭터를 계속 쓰기로 했다.

## 결정
1. **홈 위 시안 띠 제거.** 마크업·CSS·스크립트를 지운다. 역할·사용자 전환은 주소(`#role=…&user=…`)로만 한다.
2. **패널 아래 시안 줄과 "시안 조절" 제거(S2·S3).** 단계·분기·AI 지연·실패 같은 상태는 주소 키(`#panel=intake&step=…&case=…&mode=…&llm=…` 등, 06번 11절 표)로만 바꾼다. 발표·점검에 쓸 **시연 주소 목록**을 06번 11절에 둔다.
3. **화면 안 "시안" 표시를 두지 않는다.** 프론트 단계에 실제 동작이 없다는 점은 발표·시연 때 구두로 알린다(ADR-013 영향 유지).
4. **실제 로고·캐릭터 사용 확정.** `static/img/logo.png`, `static/img/mascot.png`를 헤더·날짜 카드에 쓴다. 06번 0절 원칙 6과 3절의 "중립 로고 자리"를 이에 맞춘다. 회사명 글자·상품 브랜드·사람 이름·번호 같은 **데이터**는 계속 가상이다.
5. 자체 검사(`selftest.js`)의 "화면 시안 표시 있음" 항목과 `proto=1` 검사 상태를 지운다. 대신 "화면 안에 시안 표시 문구가 없다"를 정적 검사나 자체 검사로 확인한다.

## 대안(불채택)
- 패널 아래 줄에서 문구만 빼고 "시안 조절" 버튼은 남김: 화면 안 요소가 남아 실제 화면처럼 보이지 않는다.
- 숨김(`display:none`) 유지: 쓰지 않는 코드와 문서 규칙이 계속 어긋난다.
