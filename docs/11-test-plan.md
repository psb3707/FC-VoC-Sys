## 2. Review Focus (스펙이 침묵하지만 깨지기 쉬운 입력)
| # | 입력·조건 | 기대 동작 | 소유 테스트 |
|---|---|---|---|
| 1 | 하이픈·공백·전각 숫자로 쓴 주민/카드 번호 | 차단 | 마스킹 변형 표기 |
| 2 | 업무 번호(증권 등)가 계좌 형식과 겹침 | 참조키로 처리(차단 아님) | 마스킹 번호 우선순위 |
| 3 | 한 줄 입력이 빈 값 / 아주 긴 값 / 이모지 | 검증 오류 또는 자름, 서버 오류 없음 | 입력 검증 |
| 4 | 같은 신고 이중 제출(더블클릭) | 1건만 생성 | 접수 멱등성 |
| 5 | LLM이 질문 4개 이상·이미 아는 슬롯 질문 반환 | 서버가 걸러 최대 3개 | 후처리 |
| 6 | 이미 해결/수정하지 않음인 결함에 상태 재변경·신고 연결 | 거부 또는 사유 기록 | 상태 전이 |
| 7 | 알림 수신자 중복(한 사람이 같은 결함에 2건 신고) | 1회만 알림 | 알림 대상 |
| 8 | 시행 도중 새로고침/브라우저 닫기 | 서버 시각 유지, 이어하기 또는 무효 처리 | 실험 타이머 |
